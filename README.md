# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux. Users can browse houseplants grouped by category, view each plant's image, name, description and price, add plants to a shopping cart, and manage the cart by increasing, decreasing or removing items while the totals update automatically.

## Features

- Landing page with the company name, a background image and a "Get Started" button
- About Us section describing Paradise Nursery
- Product listing page with plants grouped into categories, each showing a thumbnail, name and price
- "Add to Cart" buttons that disable once a plant is added
- Navigation bar with links to Home, Plants and Cart, plus a cart icon showing the total number of items
- Shopping cart page with item totals, the overall cart amount, quantity controls, delete buttons, Continue Shopping and Checkout

## Tech stack

React, Redux Toolkit, Vite
